# 전남대학교 통합 분실물 센터 (CNU Lost & Found Hub)
> **전대 스토어 앱 인앱 웹뷰(WebView) 및 모바일 브라우저 연동 고충실도(Hi-Fi) 프로토타입**

---

## 📌 프로젝트 소개
단과대별로 분산되어 관리되던 전남대학교 분실물 보관 체계를 **제1학생회관**과 **제2학생회관** 두 곳의 거점으로 일원화하고, 학생들이 회원가입이나 로그인 없이 즉시 접속하여 실시간으로 습득물을 검색하고 관리자와 1:1 채팅을 나눌 수 있도록 설계된 모바일 퍼스트(Mobile-First) 웹 프로토타입입니다.

---

## 🌟 핵심 디자인 및 UX 원칙

1. **전남대학교 공식 브랜드 컬러 적용**
   - 메인 컬러: 전남대학교 공식 상징색인 **딥 그린(`#006838`)**
   - 보조 색상: 신뢰감을 주는 클린 화이트(`#FFFFFF`) 및 라이트 그레이(`#F8FAFC`)
   - 상태 배지: 14일 보관 기한 임박 경고 로즈(`#E11D48`), 정보 안내 앰버(`#D97706`)

2. **무로그인(No-Login) 즉시 접근**
   - 급하게 물건을 잃어버리거나 습득한 학생들을 위해 불필요한 회원가입/로그인 단계를 전면 배제하고 접속 즉시 전체 검색 및 1:1 관리자 상담 지원

3. **실제 캠퍼스 현장 조사 인사이트 반영**
   - **거점 통합 운영:** 단과대별 분산 보관소를 `제1학생회관`(인문·사회·자연·예술·백도 권역)과 `제2학생회관`(공과·경영·농생·생활·AI 권역) 2개 통합 보관소로 일원화
   - **내향적 학생 배려:** 전화나 대면 방문이 부담스러운 학생들을 위한 **보관소 관리자 1:1 실시간 시뮬레이션 채팅** 탑재
   - **개인정보보호법 완벽 준수:** 에브리타임 등 공개 커뮤니티 노출로 인한 카드/학생증 도용 방지. 학생증·신용카드는 자동 모자이크 블러 처리되며, 본인 확인 후 현장 인도

4. **모바일 퍼스트(Mobile-First) & 데스크톱 뷰 최적화**
   - 모바일 화면(`max-w-[430px] mx-auto min-h-screen`, 테두리 및 그림자 처리) 중앙 정렬 프레임워크 적용
   - 스마트폰 상태바(Status bar) 및 전대 스토어 공식 연동 배지 적용

## 📱 주요 화면 및 기능 명세

### 1. 상단 헤더 & 보관 기한 안내 배너
- **상단 헤더:** "전남대 통합 분실물 센터" + "전대 스토어 공식 연동 채널" + "무로그인 즉시 이용" 배지
- **14일 보관 원칙 접이식 배너:**
  > 📌 *보관 기간 안내: 모든 습득물은 제1·제2학생회관 통합 보관소에 접수일로부터 [14일간] 보관됩니다. 기간 경과 시 학생지원과 인계 또는 규정에 따라 일괄 폐기되니 기한 내 수령해 주세요.*

### 2. 탭 1: [분실물 찾기] (메인 홈)
- **실시간 키워드 검색:** 물품명, 분실 장소, 세부 설명 실시간 필터링
- **보관 거점 Pill 필터:** `[전체]` | `[제1학생회관]` | `[제2학생회관]`
- **카테고리 칩 필터:** `전체`, `지갑/카드`, `이어폰/전자기기`, `우산`, `보조배터리/충전기`, `키링/액세서리`, `기타`
- **습득 단과대 구역 필터:** 인문대, 사회대, 경영대, 공과대, 도서관(백도/홍도), 기타 캠퍼스 등
- **개인정보 보호 카드 UI:** 민감 정보 물품에 `🔒 개인정보 보호 가림 처리됨` 블러 오버레이 적용
- **폐기 예정일 카운트다운 배지:** 5일 이하 임박 시 `⚠️ 폐기 임박 D-5` 펄스 애니메이션 강조
- **상세 바텀시트 모달:** 물품 상세 사양, 보관소 운영시간(10:00~18:00), 수령 안내 명시
- **연동 CTA 버튼:** *"이 물건 내 것 같아요 (보관소 관리자 채팅하기)"* 클릭 시 물품 카드 정보를 자동 첨부하여 해당 보관소 1:1 채팅방으로 즉시 이동 및 관리자 자동 안내 응답 트리거

### 3. 탭 2: [관리자 1:1 채팅]
- **보관소 선택 세그먼트:** 제1학생회관 통합관리실 vs 제2학생회관 통합관리실 실시간 전환
- **안심 본인확인 정책 안내:** 주민번호/계좌번호 요구 배제, 고유 특징 대조 후 안전 수령 안내
- **자주 묻는 질문 퀵 버튼 (Quick Reply):**
  - "🏃 지금 방문해도 수령 가능한가요?"
  - "🔍 본인 확인은 어떻게 하나요?"
  - "⏱️ 보관 기간 연장 문의"
  - "👥 대리 수령도 가능한가요?"
- **현실적인 실시간 봇 응답 시뮬레이션:**
  - 사용자가 질문 전송 시 1초 뒤 타이핑 인디케이터와 함께 친절하고 현실적인 관리자 답변 자동 생성 (발표 및 데모 시연 최적화)

### 4. 탭 3: [습득물 안내 & 입고알림]
- **섹션 A (습득자용 인계 가이드):**
  - "⚠️ 에브리타임에 사진을 그대로 올리지 마세요!" 캠페인 안내 (개인정보 침해 방지)
  - 제1학생회관 / 제2학생회관 24시간 무인 투입함 및 통합관리실 위치 안내 카드
- **섹션 B (비로그인 입고 알림 신청):**
  - 회원가입 없이 카테고리, 특징 키워드, 분실 구역, 연락처(선택)를 입력하여 유사 물품 등록 시 알림톡 수신 신청 기능 및 성공 토스트 메시지

## 🚀 실행 및 시연 방법

### 방법 1. 브라우저에서 즉시 실행 (추천 / 설치 불필요)
1. 현재 폴더에 생성된 **`index.html`** 파일을 더블클릭하거나 웹 브라우저(Chrome, Edge 등)로 엽니다.
2. React 18, Tailwind CSS, Lucide Icons가 내장되어 있어 **별도의 터미널 명령어 설치 없이 100% 동일한 기능과 모바일 인터랙션**을 바로 시연할 수 있습니다.

### 방법 2. Vite + React 개발 서버 실행
Node.js가 설치된 환경에서 아래 명령어를 순서대로 실행합니다:
```bash
npm install
npm run dev
```
기본 브라우저(`http://localhost:3000`)에서 프로토타입이 실행됩니다.
