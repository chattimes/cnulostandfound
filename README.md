# 전남대학교 통합 분실물 센터 (CNU Lost & Found Hub)
> **전대 스토어 인앱 웹뷰(WebView) 및 PC/모바일 반응형 웹(Responsive Web) 프로토타입**

---

## 📌 프로젝트 소개
단과대별로 분산 관리되던 전남대학교 분실물 보관 체계를 **제1학생회관**(인문·사회·자연 권역)과 **제2학생회관**(공과·경영·농생 권역) 두 곳의 거점으로 일원화하고, 무로그인(No-Login) 원칙으로 즉시 접근하여 실시간 검색과 1:1 상담을 나눌 수 있는 반응형 웹 플랫폼입니다.

B2B 발표 및 현장 시연을 위해 **[학생 화면 🎓]**과 **[관리자 모드 🛡️]**의 원클릭 실시간 전환 기능을 탑재했습니다.

---

## 🌟 6대 핵심 개편 사항

### 1. 이미지 엑박 원천 차단 & 인라인 SVG 일러스트
- 외부 이미지(Unsplash 등) 의존을 100% 제거하고, 각 물품의 특징을 섬세하게 표현한 **인라인 SVG 벡터 일러스트**와 그라데이션 카드 UI 직접 구현
- 전남대학교 공식 심볼 로고(`public/cnu_symbol.svg`) 및 파비콘 영구 보존

### 2. 모바일 + PC 완전 반응형(Responsive Web) 레이아웃
- 기존 모바일 고정 폭(`max-w-[430px]`) 해제:
  - **모바일(`w-full`)**: 앱 스타일 하단 탭 바(`BottomNav`) 제공
  - **PC(`md:max-w-6xl`)**: 상단 헤더 내 가로 네비게이션 탭 바 배치, 하단 탭 숨김
- **분실물 그리드**: 모바일 1~2열, PC 3~4열(`md:grid-cols-3 lg:grid-cols-4 gap-5`)
- **분할 레이아웃**:
  - `[관리자 1:1 채팅]`: 좌측(1·2학생회관 선택 & 캠퍼스 약도) / 우측(실시간 대화창) 2단 분할
  - `[습득물 안내 & 입고알림]`: 좌측(습득자 인계 가이드 & 약도) / 우측(비로그인 키워드 알림 신청) 2단 분할
- **상세 모달**: 모바일 바텀시트, PC 화면 중앙 모달(`max-w-2xl`)

### 3. B2B 시연용 '학생 모드 ↔ 관리자 모드' 즉시 전환
- 상단 헤더 우측 토글 스위치로 원클릭 전환:
  - **4대 B2B 핵심 KPI 지표 요약**: 통합 보관 중 실시간 재고, 목표 반환율(82% · KPI 배지), 14일 보관 만료 임박(D-5), 개인정보 자동 블러 건수
  - **신규 습득물 간편 등록**: 등록 즉시 학생 화면 리스트 최상단에 실시간 반영
  - **통합 재고·폐기 수명주기 관리**: `[수령 완료]` 및 `[폐기 처리]` 원클릭 상태 제어
  - **학생 1:1 문의 실시간 응대 콘솔**: 관리자가 입력한 답변이 학생 화면 채팅창에 실시간 연동

### 4. 제1·제2학생회관 캠퍼스 위치 약도(SVG) 시각화
- 전남대학교 용봉캠퍼스 형태의 인터랙티브 벡터 약도(`CampusMap.jsx`) 제공 (1학·2학 펄스 핀, 주요 랜드마크, 핀 클릭 연동)

### 5. 새로고침(F5) 데이터 보존(localStorage) & 초기화 버튼
- 신규 등록 물품, 상태 변경 내역, 채팅 메시지 전송 내역이 `localStorage`에 자동 보존
- 우측 하단 및 헤더의 `[🔄 시연 데이터 초기화]` 버튼으로 언제든 초기 6개 데이터로 원복 가능

### 6. Vercel 배포 최적화
- SPA 새로고침 404 방지를 위한 `vercel.json` rewrite 설정 완비 및 `npm run build` 무결성 검증 완료
